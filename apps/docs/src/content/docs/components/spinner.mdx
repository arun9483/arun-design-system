## When to use

- A button busy saving: "Saving…"
- A small area refreshing
- Short waits with no known end

Not for a task with a known total — use a Progress — or loading a whole layout — use a Skeleton.

**Choosing between showing progress, loading or a measurement:**

| Component                         | Use it for                                                              | For example                                   |
| --------------------------------- | ----------------------------------------------------------------------- | --------------------------------------------- |
| [Progress](/components/progress/) | A task whose completion is known, moving toward done                    | Upload at 40%, step 2 of 5                    |
| [Stepper](/components/stepper/)   | The named steps of a multi-step flow, and which one you're on           | Checkout: Cart, Shipping, Payment             |
| [Meter](/components/meter/)       | A measurement within a known range, not a task                          | Disk usage, password strength, a score        |
| **Spinner**                       | Work of unknown length, in a small space                                | A button saying "Saving…", a panel refreshing |
| [Skeleton](/components/skeleton/) | Content still loading whose shape is known, so the layout does not jump | Placeholder rows in a list, a profile card    |

`Spinner` is a native `<progress>` with no value, drawn as a turning ring. Screen readers hear
a progress bar named "Loading". Give it an `aria-label` that says more when you can, such as
"Saving draft". Under reduced motion it turns slowly instead of stopping, so it still looks
busy.

When the text beside it already says what is happening, as in a "Saving…" button, hide it with
`aria-hidden="true"`.

When you know how far along the task is, use a [Progress](/components/progress/).
