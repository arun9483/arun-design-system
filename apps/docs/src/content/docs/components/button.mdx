## Links

A bare `Button` renders `<button type="button">` — the explicit type means it never submits a
form by accident. Give it `href` for an anchor, or `render` for anything else.

## Notes

- `type` applies only to the plain button form. It is not forwarded to an anchor or to an
  element supplied through `render`.
- The `render` element owns its own attributes: `<Button render={<a href="…" />}>` needs the
  `href` on the anchor, not on `Button`.
