## Links

A bare `Button` renders `<button type="button">` — the explicit type means it never submits a
form by accident. Give it `href` for an anchor, or `render` for anything else.

## Notes

- `type` applies only to the button form. It is not forwarded to an anchor, nor to a component
  supplied through `render` — pass it on the element there.
- Pass a URL as `href` on `Button` rather than writing it on a `render` element. `disabled` has
  to be able to remove it, and a `render` element's own props outrank the component's.
- `disabled` with an `href` renders a `<button disabled>`: a link that navigates nowhere is not
  a link, and the platform then handles the tab order and activation itself.
