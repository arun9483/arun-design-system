## When to use

- Submitting a form, saving or deleting
- Opening a Dialog, a Menu or a Popover
- Any action that changes something on this page

Not to go to another page — use a Link, so it can be opened in a new tab and is announced as a link.

**Choosing between actions and navigation:**

| Component                     | Use it for                                                  | For example                     |
| ----------------------------- | ----------------------------------------------------------- | ------------------------------- |
| **Button**                    | Does something on this page: saves, deletes, opens a dialog | "Save", "Delete", "Add to cart" |
| [Link](/components/link/)     | Goes somewhere: another page, a section, a file             | "View invoice", "Read the docs" |
| [Toggle](/components/toggle/) | Turns a state on or off and stays pressed                   | "Bold", "Mute"                  |

**Choosing between rows of controls:**

| Component                          | Use it for                                                                         | For example                               |
| ---------------------------------- | ---------------------------------------------------------------------------------- | ----------------------------------------- |
| [Toolbar](/components/toolbar/)    | Several controls acting on one thing, reached with one Tab stop and the arrow keys | An editor’s formatting bar                |
| [ToggleGroup](/components/toggle/) | A set of Toggles sharing one value                                                 | Text alignment, bold / italic / underline |
| **Buttons in a row**               | A few independent actions, each its own Tab stop                                   | Cancel / Save at the end of a form        |

**Choosing a variant:**

| Variant        | Use it for                                        | For example                           |
| -------------- | ------------------------------------------------- | ------------------------------------- |
| `primary`      | The one main action of a form or dialog           | "Save", "Create account"              |
| `ghost`        | Every other action                                | "Cancel", "Edit"                      |
| `danger`       | The last step of deleting, which cannot be undone | "Delete" in the confirmation Dialog   |
| `danger-ghost` | Starting a deletion, before a confirmation asks   | "Delete" in a form footer or on a row |

## Pending

While a save is in flight, set `pending`. The button is disabled — a second press, or Enter in a
field, cannot submit again — and a Spinner turns over the label, which keeps its place so the
button does not change width. Clear it when the request settles, whether it succeeded or failed.

</Example>

With react-hook-form, pass `formState.isSubmitting`: `<Button type="submit" pending={isSubmitting}>`.

## Notes

- A bare `Button` renders `<button type="button">` — the explicit type means it never submits a
  form by accident.
- `type` is not forwarded to a component supplied through `render` — pass it on the element there.
- `Button` does not navigate. A link is a separate `Link` component.
- `pending` disables the button natively, so focus leaves it and assistive technology skips it
  while it lasts. Announce the outcome — a Toast saying "Saved", or the error — rather than the
  wait.
