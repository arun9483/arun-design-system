## When to use

- Lists, cards and profiles while their data loads
- Keeping the layout still, so content does not jump in

Not for work with no visible result yet — use a Spinner — or when the shape of the content is unknown.

**Choosing between showing progress, loading or a measurement:**

| Component                         | Use it for                                                              | For example                                   |
| --------------------------------- | ----------------------------------------------------------------------- | --------------------------------------------- |
| [Progress](/components/progress/) | A task whose completion is known, moving toward done                    | Upload at 40%, step 2 of 5                    |
| [Meter](/components/meter/)       | A measurement within a known range, not a task                          | Disk usage, password strength, a score        |
| [Spinner](/components/spinner/)   | Work of unknown length, in a small space                                | A button saying "Saving…", a panel refreshing |
| **Skeleton**                      | Content still loading whose shape is known, so the layout does not jump | Placeholder rows in a list, a profile card    |

<Example name="skeleton-basics">
  <SkeletonBasics client:load />
</Example>

`Skeleton` is a shape that stands in for content while it loads. It is hidden from screen
readers. Mark the region it fills with `aria-busy="true"` instead, and remove that once the
content arrives.

Its size and shape are yours, set with `style` or a class. It is one line of text high by
default. The shine stops under reduced motion.
