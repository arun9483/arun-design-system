`Table` is a native `<table>`, styled. Its parts map onto the table's elements: `Root`
(`<table>`), `Caption`, `Header` (`<thead>`), `Body`, `Footer`, `Row` (`<tr>`), `Head` (`<th>`)
and `Cell` (`<td>`). It sits in a container that scrolls sideways when the table is wider than
the page.

- `Head` is `scope="col"` by default. Use `scope="row"` for the first cell of a body row, so each
  cell is read with its row's name.
- Give every table a `Caption`. It names the table for screen readers.

## Sorting

Sorting is yours. Put a `<button>` in the column's `Head`, sort your rows when it's pressed, and
set `aria-sort` on the `Head`. The arrow follows `aria-sort`:

| State                              | `aria-sort`    | Arrow |
| ---------------------------------- | -------------- | ----- |
| As received, e.g. from your server | leave it off   | none  |
| Ascending                          | `"ascending"`  | ↑     |
| Descending                         | `"descending"` | ↓     |

The example cycles through all three: each press of **Amount** moves from the order the rows
arrived in, to ascending, to descending, and back. Keep the original array and sort a copy, so
you can return to it. Only the sorted column carries `aria-sort`; leave it off the others.
