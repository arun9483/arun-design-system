## Domain vocabulary belongs to your app

The design system ships only generic tones. Anything narrower — an article's difficulty, an
order's status, a build result — is your vocabulary, and mapping it at the call site keeps it
type-checked and keeps the library reusable.

## Notes

- Tones are backed by the `--color-status-*` semantic tokens, so they move with the brand.
  Override `--badge-success-bg` to restyle only success badges.
- `neutral` adds no tone class, so `.badge` alone is the neutral appearance.
