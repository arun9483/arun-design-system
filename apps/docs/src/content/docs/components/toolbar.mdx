## When to use

- An editor’s formatting bar
- Controls above a table or a canvas: zoom, filters, view
- Any row of several controls that act on the same thing

Not for two or three unrelated buttons, such as Cancel and Save.

**Choosing between rows of controls:**

| Component                               | Use it for                                                                         | For example                               |
| --------------------------------------- | ---------------------------------------------------------------------------------- | ----------------------------------------- |
| **Toolbar**                             | Several controls acting on one thing, reached with one Tab stop and the arrow keys | An editor’s formatting bar                |
| [ToggleGroup](/components/toggle/)      | A set of Toggles sharing one value                                                 | Text alignment, bold / italic / underline |
| [Buttons in a row](/components/button/) | A few independent actions, each its own Tab stop                                   | Cancel / Save at the end of a form        |

`Toolbar` is `role="toolbar"`: a row of controls that is one Tab stop. Tab in, then use the
arrow keys to move across its buttons, links, fields and toggles. Home and End jump to the ends,
and disabled items are skipped. Tab again leaves.

- `Toolbar.Button`, `Toolbar.Link` and `Toolbar.Input` are the items.
- A [ToggleGroup](/components/toggle/) inside joins the same arrow keys.
- `Toolbar.Input` keeps Left and Right for its caret until the caret reaches an end. Then the
  arrow key moves on.
- `Toolbar.Group` groups items, and `Toolbar.Separator` draws a line between them.

Name it with `aria-label`.
