## When to use

- A warning or notice about the page or account: "Your trial ends in 3 days"
- A summary of form errors at the top of a form
- The result of an action that must stay visible until it is dealt with

Not for a brief confirmation that can go away by itself — use a Toast.

**Choosing between messages and popups:**

| Component                       | Use it for                                                                                         | For example                                       |
| ------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| [Dialog](/components/dialog/)   | Something that needs a decision or input before the user carries on; the page is blocked meanwhile | Confirm a delete, edit a record in a form         |
| [Popover](/components/popover/) | Extra content or controls next to a button, while the rest of the page stays usable                | Filter panel, share options, details card         |
| [Menu](/components/menu/)       | A list of actions or settings opened from a button                                                 | "More actions ⋯", a View menu                     |
| [Tooltip](/components/tooltip/) | A short text label on hover or focus; nothing in it can be clicked                                 | Name of an icon button, a keyboard shortcut       |
| [Toast](/components/toast/)     | A brief confirmation after an action, which goes away by itself                                    | "Saved", "Archived — Undo"                        |
| **Alert**                       | A message that stays in the page until the situation changes                                       | "Your trial ends in 3 days", a form error summary |

`Alert` is a message box with a tone, an optional icon, a title and a description.

## Announcing it

An alert that is on the page from the start is just content, so it has no live role by
default. When it appears in response to something, add one so screen readers read it out:

- `role="alert"`: urgent, read out at once. A failed save, a lost connection.
- `role="status"`: polite, read out when the user is idle. "Saved", "3 results".

```tsx
{
  error && (
    <Alert.Root tone="error" role="alert">
      <Alert.Title>Save failed</Alert.Title>
    </Alert.Root>
  );
}
```

For a brief message that goes away on its own, use a Toast.

## Notes

- Tones map onto the `--color-status-*` tokens, as Badge's do. Override `--alert-error-bg` and
  the other tone tokens to restyle one tone.
