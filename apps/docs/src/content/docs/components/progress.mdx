## When to use

- File uploads and downloads
- Steps of an import or installation with a known total

Not for a measurement that is not a task — use a Meter — or work of unknown length — use a Spinner.

**Choosing between showing progress, loading or a measurement:**

| Component                         | Use it for                                                              | For example                                   |
| --------------------------------- | ----------------------------------------------------------------------- | --------------------------------------------- |
| **Progress**                      | A task whose completion is known, moving toward done                    | Upload at 40%, step 2 of 5                    |
| [Meter](/components/meter/)       | A measurement within a known range, not a task                          | Disk usage, password strength, a score        |
| [Spinner](/components/spinner/)   | Work of unknown length, in a small space                                | A button saying "Saving…", a panel refreshing |
| [Skeleton](/components/skeleton/) | Content still loading whose shape is known, so the layout does not jump | Placeholder rows in a list, a profile card    |

`Progress` is a native `<progress>`. Give it `value` and `max` to show how far along a task is.
Leave out `value` and it is indeterminate: a short bar sweeps across while you wait. The sweep
stops under reduced motion.

Name it with a `<label>` or `aria-label`, and put the percentage in the text if it matters.

## Notes

- To show how much of a range is used, such as disk space or password strength, use a
  [Meter](/components/meter/).
- Restyle with `--progress-height`, `--progress-track-color` and `--progress-bar-color`.
