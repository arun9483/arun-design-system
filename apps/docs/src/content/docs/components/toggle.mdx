## When to use

- A formatting button in an editor: Bold, Italic
- A mode that stays on: Mute, Pin
- A group of options that apply at once: alignment, list or grid view — with ToggleGroup

Not for a setting in a form or a settings list — use a Checkbox or a Switch.

**Choosing between rows of controls:**

| Component                               | Use it for                                                                         | For example                               |
| --------------------------------------- | ---------------------------------------------------------------------------------- | ----------------------------------------- |
| [Toolbar](/components/toolbar/)         | Several controls acting on one thing, reached with one Tab stop and the arrow keys | An editor’s formatting bar                |
| **ToggleGroup**                         | A set of Toggles sharing one value                                                 | Text alignment, bold / italic / underline |
| [Buttons in a row](/components/button/) | A few independent actions, each its own Tab stop                                   | Cancel / Save at the end of a form        |

**Choosing between Checkbox, Switch or Toggle:**

| Component                         | Use it for                                                                                      | For example                                |
| --------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------ |
| [Checkbox](/components/checkbox/) | A yes/no choice, or one of several independent options, that applies when the form is submitted | "I agree to the terms", "Email me updates" |
| [Switch](/components/switch/)     | A setting that takes effect the moment it is flipped, with no Save button                       | "Dark mode", "Wi-Fi", "Notifications on"   |
| **Toggle**                        | A button that stays pressed, usually in a toolbar, for a mode or formatting                     | "Bold", "Mute", "Pin"                      |

`Toggle` is a `<button aria-pressed>`: a button that stays pressed, such as Mute or Bold. Screen
readers say "pressed" or "not pressed".

To show the state in the content too, as the bell does, control the Toggle with `pressed` and
`onPressedChange` and pick the icon from the same state. Keep the name the same in both states
("Mute notifications"): `aria-pressed` already says whether it's on, and a name that changed to
"Unmute" would describe the opposite action.

## ToggleGroup

`ToggleGroup` holds the values of its pressed Toggles:

- **One at a time** by default: pressing one releases the others, and pressing the pressed one
  releases it.
- **Several** with `multiple`.
- **One Tab stop**: Tab reaches the pressed Toggle (or the first), and the arrow keys move
  along, skipping disabled ones.

```tsx
<ToggleGroup aria-label="Alignment" value={align} onValueChange={setAlign}>
  <Toggle value="left">Left</Toggle>
  <Toggle value="center">Center</Toggle>
</ToggleGroup>
```

Inside a [Toolbar](/components/toolbar/), a ToggleGroup's Toggles join the toolbar's arrow keys.

## Notes

- A choice that's on or off in a form, such as "Email me updates", is a
  [Switch](/components/switch/) or a [Checkbox](/components/checkbox/). A Toggle is for actions
  and view states.
- Restyle with the `--toggle-*` tokens.
