## When to use

- Pages deep in a hierarchy, such as Docs / Components / Breadcrumb
- Letting people go up a level without the back button

Not on a flat site, or as the only navigation.

**Choosing between moving around:**

| Component                             | Use it for                                                   | For example                    |
| ------------------------------------- | ------------------------------------------------------------ | ------------------------------ |
| **Breadcrumb**                        | Showing where the page sits in a hierarchy, with links up it | Home / Projects / Website      |
| [Pagination](/components/pagination/) | Moving between pages of one long list                        | Search results, page 3 of 12   |
| [Tabs](/components/tabs/)             | Switching between views within one page                      | Overview / Activity / Settings |
| [Link](/components/link/)             | One destination                                              | "Read the docs"                |

`Breadcrumb` is a `<nav aria-label="Breadcrumb">` around an ordered list of links. The page you
are on comes last, as `Breadcrumb.Current`: not a link, and marked `aria-current="page"`. The
`/` between steps is drawn by CSS and not read out.

## Anatomy

```tsx
<Breadcrumb.Root>
  <Breadcrumb.Item>
    <Breadcrumb.Link href="/">Home</Breadcrumb.Link>
  </Breadcrumb.Item>
  <Breadcrumb.Item>
    <Breadcrumb.Current>Settings</Breadcrumb.Current>
  </Breadcrumb.Item>
</Breadcrumb.Root>
```

Pass your router's link to `Breadcrumb.Link` through `render`, as with [Link](/components/link/).
