## When to use

- Going to another page or another site
- Jumping to a section of the page
- Downloading a file

Not for actions that change something on the page — use a Button.

**Choosing between actions and navigation:**

| Component                     | Use it for                                                  | For example                     |
| ----------------------------- | ----------------------------------------------------------- | ------------------------------- |
| [Button](/components/button/) | Does something on this page: saves, deletes, opens a dialog | "Save", "Delete", "Add to cart" |
| **Link**                      | Goes somewhere: another page, a section, a file             | "View invoice", "Read the docs" |
| [Toggle](/components/toggle/) | Turns a state on or off and stays pressed                   | "Bold", "Mute"                  |

**Choosing between moving around:**

| Component                             | Use it for                                                   | For example                    |
| ------------------------------------- | ------------------------------------------------------------ | ------------------------------ |
| [Breadcrumb](/components/breadcrumb/) | Showing where the page sits in a hierarchy, with links up it | Home / Projects / Website      |
| [Pagination](/components/pagination/) | Moving between pages of one long list                        | Search results, page 3 of 12   |
| [Tabs](/components/tabs/)             | Switching between views within one page                      | Overview / Activity / Settings |
| **Link**                              | One destination                                              | "Read the docs"                |

`Link` is always an `<a href>`, so focus, Enter, "open in new tab" and the back button are the
browser's. Use it to go somewhere. To do something, such as save or delete, use a
[Button](/components/button/).

## With a router

Pass your router's link through `render`. The styling stays, and the router handles the click:

```tsx
import NextLink from 'next/link';

<Link render={<NextLink href="/docs" />}>Docs</Link>;
```

## Notes

- There is no `disabled`: it has no meaning on a link. Render plain text instead.
- Opening in a new tab is your choice, per link: add `target="_blank"` and
  `rel="noreferrer"`, and say so in the text.
- Restyle with `--link-color`, `--link-color-hover` and `--link-underline-*`.
