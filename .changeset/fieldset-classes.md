Style a group of controls: `.fieldset`, `.fieldset-legend`, `.fieldset-description` and `.fieldset-error` draw a native `<fieldset>` and its `<legend>`, description and error as a Field's label, description and error are drawn, from the same `--field-*` tokens (`@arun-dev/ui/css/fieldset`). The fieldset loses its native frame, and a new `--fieldset-gap` token spaces the group.
