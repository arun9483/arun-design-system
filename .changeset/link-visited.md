Link marks a visited page, as a native link does: `.link:visited` takes the new `--link-color-visited` token, the accent mixed toward the body text colour, so it is distinct and keeps the required contrast for any brand and theme. Hover still changes it. Breadcrumb, Pagination and link cards are unchanged.
